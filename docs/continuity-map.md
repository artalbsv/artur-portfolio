# Working Proof — continuity and motion-intensity map

## Global narrative

The portfolio is one timeline, not a list of section animations:

`signed proof → working object → proof index → constraint axis → commerce artefacts → visual reel → human practice → method path → live systems → open channel`

The persistent graphite field, coordinate label and progress rail survive every boundary. Their state changes with the active chapter and scroll velocity, so a completed section leaves visual memory rather than resetting the interface.

## Motion layers

| Layer | Responsibility | Runtime rule |
| --- | --- | --- |
| Ambient | Persistent hairlines, coordinate state, progress and microscopic velocity response | One shared RAF only while scroll energy is settling; pauses with the tab |
| Responsive | Direct manipulation, proof preview, gallery, discipline/experience selection, email intent | Local to hovered/focused/active instruments; keyboard and touch have explicit states |
| Event | Signature, hero opening, project title assembly, before/after story, catalogue morph and closing assembly | Short GSAP timelines; one dominant event per viewport |

## Transform ownership

- Scroll wrappers own scroll translation only.
- Perspective wrappers own tilt/rotation only.
- Frames own structure and never receive GSAP transforms.
- Screens own native media geometry and never move unless there is real overflow to reveal.
- The persistent ambient layer owns global velocity response; sections do not start competing RAF loops.
